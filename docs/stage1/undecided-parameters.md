# 未决参数清单（stage-1，issue #13 验收项）

对应 issue #13 验收标准：「所有未定参数都有状态、单位及确认记录；示例配置不能被当作用户已批准规则。」

本清单覆盖 `docs/project-spec.md` §12 的全部类别，并汇总 §2（作废边界）、§3–§9 中散落的未决点。约定：

- **状态列全部为「未确认」**。这是刻意要求：stage-1 只负责把参数显式列出并给出可比较方案，不替业务拍板（spec §12：不能把影响交易双方权利或计费口径的选择暗中定稿）。
- **候选方案**是供比较的具体选项及其影响，不是已选方案。个别方案标注「工程倾向」时，仅代表实现建议，仍需确认。
- **确认后**：在该行更新状态，并在 `decision-log.md` 中记录确认人、日期与结论。
- **模块名**（chaincode/depin、backend、worker、experiments、network）为本仓库计划命名，最终以实现为准。
- 仓库中任何示例配置文件里出现的数值（单价、系数等）均为「可运行示例」，**不是**已批准规则。
- **【2026-09-13 计费口径变更，D1】**：计费改为「模板工作单元」（docs/stage1/decision-log.md D1）。受影响条目状态已更新：O1–O6 关闭（不再按精度计数计费）；M1 改写为「工作单元采信证据」；M2/M4/R2 降级为非计费阻塞；E1–E3 改写为模板单价表。精度权重 w_p 维度整体废止。
